      About the data

      Source

      Bureau of Infrastructure and Transport Research Economics (BITRE), Hospitalised injury data, September 2023.

      Cases where the person died in hospital within 30 days are excluded. Each figure is a count of hospitalised injuries, not a rate: the data has no measure of how much people drive, ride or walk.

      Reading the charts

      • Series breaks. Victoria (2012) and NSW (2017) changed how emergency-only cases are counted, so those years are not strictly comparable.
      • Average stay. Bed days per case. Coding changed in 2015.
      • Not published (n.p.). Small state cells are suppressed, so shares use published cells only.
      • Map. State and territory boundaries: ABS Australian Statistical Geography Standard (ASGS) 2021, simplified, CC BY 4.0.
      • Filters. State and First Nations files hold one dimension at a time, so they use the latest filter their file supports. Each card's badge says what it is showing.
